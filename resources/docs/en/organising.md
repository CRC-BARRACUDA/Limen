# Favourites, categories and search

## Favourites

The star on a module card keeps it at the top of the list. It is remembered
between sessions.

## Categories

Your own groupings. Open the **Categories** tab to create one, rename what is in
it, or remove it. A module can be in several at once.

On the **Modules** page the category dropdown narrows the list to one group.
Unlike a favourite, that choice is *where you are looking*, not a preference —
it is not remembered when you come back.

## Search

The search box matches a module's name, its description and its tags at the same
time, in whichever language the description is shown in. Favourites stay first
inside whatever the search leaves.
