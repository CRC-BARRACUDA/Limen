# Getting started

Limen is a console for tools. It does almost nothing by itself: every job — reading
a machine's devices, parsing a suspicious message, asking a fleet a question — is
done by a **module**, and Limen loads them, keeps them apart, and gives them one
look and one language.

It is portable. The whole program is one folder you can carry on a USB stick, run
on a machine, and take away again. Nothing is installed and nothing is left
behind.

## Where to start

- **Modules** — everything installed, and everything available to install. Start here.
- **Categories** — your own groupings, for when the list gets long.
- **About** — the version, the build, and the licence.

Each module opens in its own **tab**. Tabs are closable and independent: a scan
running in one keeps running while you read another.
