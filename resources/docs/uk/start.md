# Початок роботи

Limen — це консоль для інструментів. Сама по собі вона майже нічого не робить:
кожну задачу — прочитати пристрої комп'ютера, розібрати підозрілий лист, запитати
щось у парку машин — виконує **модуль**, а Limen завантажує модулі, тримає їх
окремо один від одного й дає їм спільний вигляд і спільну мову.

Програма портативна. Це одна тека, яку можна носити на флешці, запустити на
комп'ютері й забрати з собою. Нічого не встановлюється й нічого не залишається.

## З чого почати

- **Модулі** — усе встановлене й усе доступне для встановлення. Почніть звідси.
- **Категорії** — ваші власні групи, коли список стає довгим.
- **Про програму** — версія, збірка та ліцензія.

Кожен модуль відкривається у власній **вкладці**. Вкладки незалежні й їх можна
закривати: сканування, запущене в одній, триває, поки ви читаєте іншу.
